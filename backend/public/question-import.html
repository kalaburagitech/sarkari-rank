JSON format reference (all fields) 
[
  {
    "question": "Who is known as the Father of the Indian Constitution?",
    "options": ["Mahatma Gandhi", "Dr. B.R. Ambedkar", "Jawaharlal Nehru", "Sardar Patel"],
    "answer": "B",
    "explanation": "Dr. B.R. Ambedkar chaired the Drafting Committee.",
    "subject": "Indian Polity",
    "difficulty": "easy",
    "marks": 1,
    "negativeMarks": 0.25,
    "questionKn": "ಸಂವಿಧಾನದ ಪಿತಾಮಹ ಯಾರು?",
    "optionsKn": ["ಮಹಾತ್ಮ ಗಾಂಧಿ", "ಡಾ. ಬಿ.ಆರ್. ಅಂಬೇಡ್ಕರ್", "ಜವಾಹರಲಾಲ್ ನೆಹರು", "ಸರ್ದಾರ್ ಪಟೇಲ್"],
    "explanationKn": "ಡಾ. ಅಂಬೇಡ್ಕರ್ ಕರಡು ಸಮಿತಿಯ ಅಧ್ಯಕ್ಷರಾಗಿದ್ದರು."
  }
]
  • question (required) — the question text. Aliases: questionText, q, text.
  • options (required) — array of 2–6 strings. Aliases: opts, choices.
  • answer (required) — correct option as a letter (A/B/C…), a number (1-based), or the exact option text. Aliases: correct, ans.
  • explanation, subject, topic, difficulty (easy/medium/hard), marks, negativeMarks, language — optional; fall back to Step-2 defaults.
  • questionKn, optionsKn, explanationKn — optional Kannada translations for bilingual tests.
